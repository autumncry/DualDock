# DualDock 3.0 · 多屏应用与工具页

最初在 2.8.6 独立试用版验证交互，当前功能分支已整合 v2.9.2。实际试用步骤见[试用指南](../试用指南.md)。

## 使用场景

MacBook 的 Dock 保留日常应用和分组。外接屏打开工具页，显示正在播放、天气、下一个会议及常用快捷指令。暂停音乐后，当前文稿仍是原来的前台窗口。反向滑动可以回到刚才浏览应用的位置。

## 首版建议

| 来源 | 在 DualDock 中的具体用法 |
| --- | --- |
| PrimoDock 的多屏工作区 | 每块屏幕独立记住当前页。用户编排一次工具，两块屏都可以使用这套排列。 |
| PrimoDock 的不同宽度卡片 | 音乐可用三格，日程两格，天气或快捷指令一格。窄栏先省略次要内容，点击后在本屏展开详情。 |
| Docky 的可组合工具和 Smart Stack | 音乐、日历、天气既可独立排列，也可将同宽且适合轮换的卡片放进一格。堆栈提供上一张、下一张操作。 |
| DualDock 原有的应用栏 | 应用页继续使用现有分组、角标、预览、窗口操作与尺寸设置。工具页与“仅显示运行应用”分别保存。 |

### 手势和显示

- 底部和顶部 Dock 上下翻页、左右浏览溢出内容。侧边 Dock 交换两轴。判定方向后锁定到手势结束，处理松手后的惯性。
- 在应用与工具页之间做双向跟手过渡。短滑松手可以取消，一次手势最多换一页。另提供明确的点按入口，并响应“减少动态效果”。
- 翻页手势归当前屏幕的主栏。展开的应用夹、窗口预览、图标拖拽、边缘调整尺寸优先处理自己的输入。单个堆栈用可点击的页码或箭头切卡。
- 常用设置放在现有 Dock 设置分类下。用户能添加、移除、排序工具，再选择宽度或把卡片放入堆栈。

### 首批真实工具

| 工具 | 首版操作 | 无数据时的体验 |
| --- | --- | --- |
| 音乐 | 先适配本机音乐 App，显示曲名、暂停或继续、下一首。控制前按需申请自动化权限。 | 播放器未运行时显示“打开音乐”，仅在用户点击时启动。 |
| 日历 | 显示日期。经用户授权读取下一项日程，点击查看当天安排。 | 拒绝日历权限时保留日期，无日程时显示当天已无安排。 |
| 天气 | 选择城市，栏内显示气温和天气状况。详情提供预报，所有屏幕共享缓存。 | 离线时保留最近数据并显示更新时间。本地版以 MET Norway 获取近时预报，备用 Open-Meteo。 |
| 快捷入口 | 打开用户添加的应用、文件夹、网址，或运行用户选定的 macOS 快捷指令。 | 目标失效时提供重新选择入口的操作。 |

### 工具页与工作区

用户给音乐换歌时，工具页只负责播放控制。设计中的“工作区”则是一套有名称的应用及工具布局，可以逐屏选择。如果今后需要“写作”“开发”等多套布局，可以沿用同一份卡片定义，为每套布局保存独立的排列与堆栈。是否同时管理已打开的窗口，属于单独的产品选择。

### 实施顺序与验收

1. **原生双页与多屏。** 将当前页放在每屏面板的状态中。应用启动、退出或刷新图标时，工具页仍留在原处。验证四向停靠、斜滑、惯性、超过屏宽、全屏唤出、减少动态效果。
2. **卡片与编排。** 接上上述四类工具及卡片设置。多屏共享音乐、日历、天气的数据源。安装升级保留已有分组和顺序，断开、接回外屏后恢复该屏的选择。
3. **扩展边界。** 首批原生卡片共用稳定的标识、尺寸、摘要、详情与动作定义。第三方 SDK、组件商店和复杂自动切换规则另行评估。社区组件协议独立设计，项目继续沿用现有许可。

**尚待确定的是，手动滑到工具页时是否同时管理应用窗口。**原型采用“切 Dock 内容，当前文稿继续工作”。如果需要像 PrimoDock 一样收起整组窗口，建议为“切换工作区”设置独立入口，并单独验证多桌面、全屏、最小化窗口与外接屏断连后的恢复。
