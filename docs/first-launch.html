DualDock

首次安装

把 DualDock 3.app 拖入 Applications，弹出磁盘映像，再从“应用程序”打开 DualDock。

如果 macOS 提示“无法验证开发者”

当前版本未经过 Apple 公证。请确认安装包来自 DualDock 官方发布页且文件完整。

  1. 尝试打开 DualDock 一次，关闭验证提示。
  2. 进入 系统设置 → 隐私与安全性 → 安全性，找到 DualDock，点击仍要打开。
  3. 按系统提示确认。如果找不到按钮，再尝试启动一次后返回此页。

如果系统明确报告恶意软件或文件损坏，请停止打开，重新下载并核对发布页的 SHA-256。

可选：复制终端命令

确认应用已复制到下列路径后，可复制这两行，在“终端”中检查并执行。第一行移除 DualDock 的下载隔离标记，第二行打开应用。

First installation

Drag DualDock 3.app to Applications, eject the disk image, then open DualDock from Applications.

If macOS cannot verify the developer

This build has not been notarized by Apple. Confirm you obtained an intact copy from the official releases.

  1. Try opening DualDock once and dismiss the verification alert.
  2. Go to System Settings → Privacy & Security → Security. Find DualDock and click Open Anyway.
  3. Confirm when macOS asks. If the button is missing, try opening the app again, then return to settings.

If macOS reports malware or a damaged app, stop and download a fresh copy. Compare its SHA-256 with the release checksum.

Optional Terminal commands

After copying the app to the path below, copy these two lines, review them in Terminal, and run them. The first removes the download quarantine flag from DualDock. The second opens the app.

xattr -dr com.apple.quarantine "/Applications/DualDock 3.app"
open "/Applications/DualDock 3.app"
