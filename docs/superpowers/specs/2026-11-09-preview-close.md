# DualDock 1.2.4：关闭预览窗口

每张预览缩略图右上角加入独立 × 按钮，贴合图片实际显示区域；普通点击缩略图仍切换窗口。按钮具有可访问性标签和悬停反馈，图片与关闭命中互不穿透。

点击 × 后收起当前预览，通过辅助功能调用对应窗口原生关闭按钮。校验实时应用、进程启动时间及窗口 ID；私有 ID 映射不可用时，回退要求原始标题和几何信息在辅助功能及实时窗口集合中均能唯一匹配，信息缺失或歧义时提示重试。禁止用当前前台窗口、Cmd-W 或退出应用代替。

关闭请求成功不代表窗口已消失：原应用可能显示未保存内容确认。DualDock 不选择保存或丢弃；原窗口仍存在时可激活原应用展示确认。再次悬停重新获取窗口列表，不保留失效预览。

验证覆盖重复标题/位置、窗口过期、进程重启、回退歧义、关闭按钮命中和打开/关闭回调隔离。测试不关闭用户已有窗口。
