# 手动尺寸随内容伸缩与连续尺寸更新

用户确认：保留长度调节，用来重新设定两侧留白。

- 原完全自适应模式不变。新增独立手动选项，默认关闭。
- 开启时按当前有效长度与静止图标行计算两端相同留白，最小为6pt；若内容已溢出，以最小留白补足容纳空间。
- 应用增减、分组变化、图标比例、厚度与间距变化驱动实际内容长度。栏始终居中；达到适用屏幕上限后保留手动滚动，无滚动条。
- 长度滑块与两端拖动重设留白；关闭选项恢复原固定长度。厚度和图标参数仍可手动设置。
- 同步模式采用共同范围，独立模式按各屏保存留白和尺寸；离线屏幕在重连后用自己的有效范围初始化。满屏且无实际位移的拖边不能丢失已有留白。
- 连续配置更新复用图标视图并合并几何更新，结构/方向/拓扑变化仍完整刷新。连续外观写入延后150ms，编辑结束、拖边提交及退出时刷新保存；结构变更立即保存。
- 验证区分隐藏组件回放、真实设置操作和人工拖动手感，不将回放耗时描述成屏幕帧率。
