# DualDock 1.3.0：独立高度和宽度

用户要求两个独立滑块，并确认高度上限为最矮屏幕有效高度的 12%。宽度上限为最窄屏幕的完整有效宽度。两项约束分别取所有逻辑屏幕对应轴的最小值，使用 macOS 缩放后的逻辑点。

高度指可见底板高度，图标等比例缩放，悬停的放大幅度仍独立。宽度直接控制主栏宽度，不随高度、间距、应用数量或模式变化重新计算。内容超出时仍可手动横向滚动，组弹窗继续按成员自然定宽。

AppStore 持有一份共同的屏幕限制，设置页和主栏都读取它。DisplayCoordinator 用同一 NSScreen 快照更新限制、建立各显示器的栏；镜像只建立实际需要的窗口。期望宽度和高度保存在配置中，屏幕变小时只限制有效值，不覆盖偏好。暂时没有屏幕信息时保留最后有效范围。

schema5 新增显式栏宽。旧数据首次迁移时，在取得运行应用及有效屏幕信息后，用原布局计算当前宽度并持久化，包含未固定运行应用；不能只按固定条目计数。首次无屏幕时延后迁移，避免用默认范围永久缩小栏宽。升级保留原配置备份。

最小宽度根据共同高度上限保留图标显示空间，不能依赖滑块当前高度，否则会重新耦合两项尺寸。放大峰值按实际固定视口限制，避免窄栏裁切。

验证覆盖宽高互不联动、共同最小轴限制、屏幕增减及恢复、空屏幕过渡、完整屏宽上限、旧布局迁移、内容溢出与浮窗行为。
