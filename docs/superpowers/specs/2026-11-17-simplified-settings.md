# 简化尺寸与原生设置重设计

用户确认采用HTML参考的简化逻辑和新版界面，并保留已有配置。原生macOS设置，中文优先，保留图标和标语，使用系统语义颜色与控件。主要入口为大小（绝对图标pt）、疏密（0…1）和长度（贴合、占满、固定比例）；高级可覆盖间距、两端留白、高度下限、长度占比、对齐和溢出缩小。每项恢复自动及当前作用范围恢复推荐。

跟随系统Dock作为独立尺寸模式保留。每屏位置独立、尺寸可同步；高度12%上限及可用边长上限保留。旧数据schema9无新增自定模型时沿原渲染路径精确显示，直到用户修改新控件；读取设置不改变布局。迁移为schema10并备份原始字节。

设置页采用原生侧栏与轻量分组，大小/位置展示生产几何预览，分类切换回顶部，820pt小窗口改用纵向布局。高级手动值会明确标记；间距和留白都固定时禁用无作用的疏密滑块，提供恢复联动。

测试涵盖新模型、旧配置、显示器重连/同步、四向拖动零位移、数值边界、原生模式隔离及连续保存合并。UI验收区分隐藏组件渲染、WindowServer自身夹具截图和真实用户操作。
