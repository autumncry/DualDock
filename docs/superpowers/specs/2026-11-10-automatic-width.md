# 可选自动宽度

新增“自动调整 Dock 宽度”，默认关闭。开启时按当前显示的主栏条目自动计算宽度，手动宽度滑块禁用；关闭时恢复此前保存的手动宽度。自动模式不改写手动宽度，也不接管高度设置。

普通模式按固定应用、折叠组与尚未固定的运行应用计算；组为一个主栏条目，已固定或在组中的运行应用不重复计数。仅运行模式采用既有平铺列表。应用数量变化触发现有显示器刷新，所有屏幕使用同一个有效宽度，并保持最窄屏幕上限和溢出滚动。

用户进一步确认，自动模式按实际内容计算：当前间距、图标大小和数量都参与栏宽，悬停动画不改变栏宽。固定模式仍保持间距与栏宽独立。旧参考间距只保留用于旧配置的手动宽度迁移。schema6新增布尔开关，旧配置默认关闭；已有手动宽高、分组和其他设置保留。

验证覆盖应用增加/减少、重复固定、分组计数、仅运行模式、开启/关闭与重启恢复、多屏限幅、高度可调、自动模式间距联动、固定模式间距独立以及悬停不改变宽度。
