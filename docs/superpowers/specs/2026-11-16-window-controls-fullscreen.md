# 窗口选择、重复点击与全屏边缘唤出

基线：2.2.2 / 98b822e。此前弹窗遮挡导致缩放失效及高度说明已落地，保留已有实现和用户配置。未跟踪的 .impeccable/ 内容不属于本轮交付。

## 已确认行为

- 右键应用图标，在菜单顶部列出该应用的可操作窗口（包括最小化窗口），勾选当前目标；选择后立即激活并记住该窗口。窗口列表不依赖截图是否可获取。
- 点击图标：未运行则启动；目标在后台则前置；目标已前台则最小化；再次点击还原同一个窗口。多窗口时优先用户所选，目标关闭后重新选择有效焦点/主窗口。
- 真正全屏及铺满工作区的最大化窗口不参与最小化切换，只激活。
- 使用系统原生最小化按钮/AX最小化状态与窗口唤起；动画由系统和目标应用提供，不制作替身窗口动画。
- 全屏时默认隐藏该屏DualDock；指针停留在其边缘后唤出，进入栏、应用夹或预览后保持可用，移开后隐藏。其他屏幕独立。此规则替代旧版全屏强制隐藏规则。
- 隐藏系统Dock开关继续控制系统偏好并维护恢复记录；不破坏Spaces/Mission Control。全屏下系统Dock竞争需要实机核对，不凭策略测试宣称已解决。

## 实现边界

窗口身份由PID、进程启动时间、应用路径和窗口ID共同标识，操作前重新校验。辅助功能读写在串行后台队列执行并设超时，过期请求不能作用于新窗口；窗口选择仅保存在内存。无权限/无准确目标时保留原生应用打开回退，不能随意最小化其他窗口。

可见性策略与窗口层级分别处理：纯状态机决定隐藏/唤出，AppKit窗口在唤出时加入对应全屏空间，隐藏后移除附加资格以避免切换闪现。所有菜单、分组、预览继承所属屏幕的全屏呈现行为。
