# DualDock 1.2.1：固定底板与简化入口

## 用户要求

用户再次观察到悬停会放大整条 Dock。此次修改要求底板保持不变，只有鼠标指向的图标放大。移除最右侧的模式和设置按钮；设置可从 Dock 空白处右键或菜单栏进入，显示模式只在设置页切换。完成后上传现有 Git 仓库。

用户随后补充：展开应用组时圆角外露出矩形底色，需要处理背景边角。

## 原因与实现

1.2.0 只固定了水平方向，根视图仍是随最高图标增高的毛玻璃视图；邻近图标也采用余弦波同步放大。这两个行为都不符合此次明确要求。

将根视图改为透明画布，内部使用尺寸固定的毛玻璃底板；画布在初始化时预留最大图标高度。仅当前命中的固定槽位图标缩放，其他槽位不移动。悬停动画不改变窗口、底板、视口、文档尺寸或滚动位置。透明上方区域使用鼠标命中判定控制窗口透传，避免挡住背后的应用。

显示模式唯一交互入口为设置页现有单选项。主栏空白处右键提供设置菜单，菜单栏保留设置和退出等入口。保留已有分组、角标、跨屏共享配置以及无滚动条的手动横向滚动。

圆角裁切限制在独立的毛玻璃背景层，使展开应用组的背景在圆角外透明；不裁切整个图标画布。

## 验证重点

- 无悬停、中心/两端图标悬停和动画中间帧的底板、窗口尺寸一致。
- 非目标图标的 frame 不变，底板上方图标未裁切；命中依据固定槽位，不由放大后的重叠框改变目标。
- 溢出内容的手动滚动位置在悬停中保留，横向/纵向滚动条均关闭。
- 透明区域不截获桌面点击；实际可见图标仍支持点击、拖拽和右键。
- Dock 视图不包含模式和设置按钮，菜单栏无模式切换，设置页仍能切换。
- 应用组背景圆角外透明，不露出矩形底色，图标和角标完整。
- 保留个人配置；构建、签名、DMG 校验和已有回归通过后发布到私有仓库。

真实鼠标手感、热插拔等人工检查只按已取得的证据记录，不以离屏布局回放代替全部实机验收。
