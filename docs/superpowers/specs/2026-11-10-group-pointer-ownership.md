# 应用夹弹窗的鼠标归属

用户报告展开应用夹后，指针移向成员时整个弹窗偶发收起。问题随后暂时恢复，需要针对可复现的事件路径修复。

主栏与应用夹都监听全局鼠标移动。快速打开分组时，主栏尚在放大动画中，透明画布和下方图标可能与弹窗或其上方过渡路径重叠。旧逻辑仍向下层主栏发送悬停，主栏应用的悬停会立即关闭应用夹。不同窗口的离开事件还可能取消新成员的预览。

上层预览、应用夹及来源图标上方的短过渡区优先接管指针。下层条暂停动画并结束原悬停一次，之后返回同一图标仍会产生新的进入事件。预览取消与退出计时均绑定当前来源，忽略其他条的陈旧离开事件。

指针斜向移入较远成员时，可能短暂经过真正的主栏邻居图标。复用现有450ms预览悬停等待：只有稳定停留、仍在对应图标且未被弹窗遮挡时，才收起旧应用夹并开始截图。点击行为保持即时，离开有效区域的关闭规则保持原样。

回归覆盖实际重叠坐标、过渡区、陈旧事件顺序、短暂经过邻居、稳定主栏悬停、同图标重新进入、正常退出及隐藏弹窗。组件检查不投递桌面输入或读取用户窗口内容。
