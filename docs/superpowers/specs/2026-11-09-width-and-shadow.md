# DualDock 1.2.5：间距独立于栏宽

用户要求调节“图标间距”时主 Dock 的横向宽度保持不变，并指出放大图标外围出现黑边。

主栏新增持久化的栏宽参考间距，配置 schema 升至 4。升级时从原图标间距派生，保留当前外观作为宽度基准；新的实际间距只控制内容行。主栏宽度按参考间距、应用数和现有大小参数计算，重启后仍独立。内容缩紧时居中，超出固定视口时保留无滚动条的手动横向滚动。应用夹弹窗继续按实际成员间距自动适配。

Antify 原始系统图标及实际 DockTile 的离屏绘制均没有硬黑描边。关闭主栏的 `hasShadow`，保留图标素材和组/预览浮窗的正常阴影。完全屏外的 WindowServer 阴影 A/B 捕获被系统拒绝，随后安装到正式位置，用户实屏确认黑边消失，确认额外窗口阴影为此处轮廓来源。

验证覆盖间距全范围的固定主栏尺寸、多个屏宽、适配/溢出转换、大小与应用数调整、旧配置保宽迁移和重启一致性，并检查现有放大动画、滚动范围及应用夹布局不回退。
