DualDock 1.2.0

系统要求
macOS 14 或更新版本。此 arm64 安装包适用于 Apple Silicon Mac。

安装
1. 将 DualDock.app 拖到本窗口的 Applications 文件夹。
2. 弹出 DualDock 磁盘映像，再从“应用程序”打开 DualDock。
3. 在菜单栏双矩形图标中打开设置，在“权限”页授予屏幕录制与辅助功能。
4. 系统 Dock 隐藏默认关闭，可在设置中主动开启。

此构建采用本地临时签名，未经过 Apple Developer ID 签名和公证。
从 GitHub 下载后，macOS 可能阻止首次打开。确认来源后，可前往
“系统设置 → 隐私与安全性”中选择“仍要打开”。

源码、版本说明和 SHA-256 校验文件
https://github.com/autumncry/DualDock/releases/tag/v1.2.0
仓库当前为私有，需要登录有访问权限的 GitHub 账号。

配置保存在 ~/Library/Application Support/DualDock/。
正常退出会恢复由 DualDock 修改的系统 Dock 设置。
