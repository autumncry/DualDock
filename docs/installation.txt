DualDock 3.0.0

系统要求
macOS 14 或更新版本。此 arm64 安装包适用于 Apple Silicon Mac。

安装
1. 将 DualDock.app 拖到本窗口的 Applications 文件夹。
2. 从“应用程序”打开 DualDock。首次验证的图文步骤和复制命令按钮位于本磁盘的“首次安装 - First Launch.html”。安装完成后弹出磁盘映像。

首次启动：Apple 无法验证或无法验证开发者
此构建采用本地临时（ad-hoc）签名，未经过 Apple Developer ID 签名和公证。
首次打开可能提示“Apple 无法验证 DualDock 是否包含恶意软件”或“无法验证开发者”。
仅当安装包来自本项目官方 Releases、你确认来源可信且文件未被篡改，并决定继续时，
按以下步骤允许这一个应用：
https://github.com/autumncry/DualDock/releases/latest

1. 将应用复制到“应用程序”后，先尝试打开 DualDock，再关闭验证提示。
2. 打开“系统设置 → 隐私与安全性”，向下滚动到“安全性”，找到 DualDock 的阻止记录，
   点击“仍要打开（Open Anyway）”；部分系统会先显示“打开”入口。
3. 按要求验证登录密码或 Touch ID，然后在确认提示中选择“打开”。之后可正常双击启动。
4. 找不到按钮时，再次尝试打开“应用程序”中的 DualDock，再返回上述页面。
   Apple 说明该入口通常在尝试启动后约一小时内可用；受管理的 Mac 可能需要联系管理员。

可选：使用终端打开
选择命令行方式前，请确认应用来自上方官方 Releases、来源可信且未被篡改，
并已复制到 /Applications/DualDock.app。打开“终端”，依次执行：

xattr -dr com.apple.quarantine "/Applications/DualDock.app"
open "/Applications/DualDock.app"

第一条命令仅移除这个应用包及其内部文件的 com.apple.quarantine 隔离属性，
不清除其他扩展属性，也不关闭系统整体的 Gatekeeper。第二条启动应用。
这不会为应用签名或公证，也不会授予辅助功能或屏幕录制权限，仍需单独授权。
请保持完整路径不变，不要默认添加 sudo；如遇权限错误，可使用上方系统设置方式。
该方法经用户本机验证可用，但未覆盖所有 Mac 和 macOS 版本。

如果提示“将损坏你的电脑”、检测到恶意软件或“已损坏”，请停止打开，从官方 Releases
重新下载并核对 SHA-256；仍有提示时前往以下地址反馈，不要按上述流程放行：
https://github.com/autumncry/DualDock/issues
这与“无法验证开发者”不同。无需关闭系统的整体安全保护。

从现有版本升级
已安装 DualDock 2.8.0 或更高版本时，可从“支持 → 关于 DualDock → 检查更新”直接升级。通过 DMG 安装时，请退出旧版，用本磁盘的 DualDock.app 替换“应用程序”中的同名应用。
如果系统能找到旧试用配置，首次启动会先备份已有正式版配置，再导入试用版的应用组、屏幕设置和工具页排列。备份目录为 ~/Library/Application Support/DualDock Backups/。没有试用配置时继续使用原有设置。
曾为独立试用版开启登录启动的用户，可在 macOS 的“登录项与扩展”检查并关闭旧试用项。

首次使用
1. 右键 Dock 空白处或点击菜单栏双矩形图标打开设置，在“权限”页授予屏幕录制与辅助功能。
2. 在“外观与尺寸”选择“自定义”或“跟随系统 Dock”，在“多屏和显示内容”中为每块屏幕选择位置。
3. 自定义尺寸提供大小、图标间距、长度；高级设置可精确调整并逐项恢复自动。
4. 系统 Dock 隐藏默认关闭，可在“通用”中主动开启；正常退出会恢复原设置。
5. 在“交互”中可开启“最大化窗口时隐藏 Dock”，鼠标移到对应边缘稍作停留即可唤出。
   该选项默认关闭；使用应用夹、预览和菜单时保持显示，真正全屏时也支持边缘唤出。
6. 手动模式下，“交互”提供“放大峰值”和“联动范围”滑块；跟随系统模式不开放手动曲线调节。
7. 右键应用图标可选择窗口；后台窗口先前置，普通前台窗口再点最小化，继续点还原。
   全屏和最大化窗口只激活。动画由系统与原应用提供。

应用页与工具页
将指针放在 Dock 上，水平 Dock 用双指上下滑动切页，竖向 Dock 用双指左右滑动切页。每块屏幕记住自己的页面。也可从菜单栏选择“切换本屏应用页与工具页”。
在“设置 → Dock → 工具页”点击“编辑”，从组件库拖入所需工具、排序或调整宽度，点击“确定”后在各屏生效。
组件库提供系统状态、专注计时、音乐、天气、日历、快捷入口，以及 Codex、Gemini、Claude、Cursor 的额度卡。

尺寸与位置
大小决定图标。图标间距 0 表示可见边界贴合，100 表示约一个图标宽度；留白可在高级设置中独立调整。
长度可贴合、占满或按比例固定。达到上限后可滚动；高度最多占适用屏幕短边的 12%。
每屏位置独立，尺寸可选择同步。旧尺寸保留为自定值，恢复联动或推荐设置可回到自动计算。
布局示例使用五个固定图标，随设置变化，不反映实际打开的应用。

后续更新
在“设置 → 支持 → 关于 DualDock”点击“检查更新”，查看变更并确认安装。已有 2.8.0 及以上正式版也可以从这个入口升级。
