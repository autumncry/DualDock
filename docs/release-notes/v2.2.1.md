# DualDock 2.2.1

## 中文

- 修正调节长度或厚度时，系统窗口取整与内部小数坐标不一致导致的栏中心往复偏移。保留连续尺寸值，补偿实际窗口与目标位置之间的差值。
- 统一图标滚动区域与底板的坐标，避免单独像素对齐造成图标行的小幅跳动。
- 同时覆盖四个方向的定位，以及首次布局、尺寸更新和应用数量变化；原有手动自动长度、留白、分组和尺寸同步设置保留。

macOS 14+，Apple Silicon。采用 ad-hoc 签名，未经 Apple 公证。提供 DMG 与 SHA-256 校验文件。

## English

- Corrected center drift during length and thickness adjustments caused by native window rounding differing from fractional content coordinates. Continuous size values are retained while the difference between requested and actual window positions is compensated.
- Kept the icon viewport and backdrop in the same coordinate system, avoiding row movement caused by independent pixel alignment.
- Covers all four orientations, initial layout, size updates, and app-count changes. Manual content-driven length, end padding, groups, and display synchronization settings are preserved.

Requires macOS 14+ on Apple Silicon. The build is ad-hoc signed and not Apple-notarized. DMG and SHA-256 assets are provided.
