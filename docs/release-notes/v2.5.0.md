# DualDock 2.5.0

- “通用”加入简体中文和 English 显示语言。设置、菜单栏、Dock 菜单和操作提示可随时切换，重新启动后记住选择。
- 高级设置中的高度滑块改名为“Dock 高度”。
- 修复首次设置登录启动时开关变灰的问题。macOS 尚未找到登录项记录时，可点击开关登记。实际启用状态由 macOS 提供。

Requires macOS 14 or later on Apple Silicon.

- Switch between Simplified Chinese and English in **General → Display Language**. The choice takes effect immediately and is remembered on restart.
- The advanced height control is now labeled **Dock Height**.
- Fixed a disabled Launch at Login switch when macOS has no login item record yet. DualDock now requests registration when you enable the switch and reads back the system status.

首次安装如遇 Apple 验证提示，请参照随 DMG 提供的“安装说明.txt”。 [Installation guide](https://github.com/autumncry/DualDock/blob/main/README.en.md)
