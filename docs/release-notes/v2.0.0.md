# DualDock 2.0.0

## 中文

- 完整自适应：跟随系统 Dock 的基础图标大小、栏厚度、图标间距、端部留白和悬停放大，长度随应用数量变化并保持居中。开启时隐藏手动尺寸控件，关闭后恢复手动配置。
- 每屏位置：各显示器可独立选择底部、顶部、左侧或右侧；侧边采用竖排，图标保持正向，应用夹与窗口预览向屏幕内侧展开。
- 手动缩放：拖动内侧边调整厚度、两端调整长度、内侧两个角等比缩放。可单独调整图标比例，后续缩放保留比例。
- 多屏尺寸：可同步全部屏幕，也可分别设置；重新同步时采用设置页当前所选屏幕的尺寸。不同屏幕的位置始终独立保存。
- 全新设置：左侧分类、右侧配置，新增“关于”页；窗口支持缩放和最小化。
- 保留已有分组、顺序、角标、预览关闭按钮及权限配置；升级自动备份旧配置。

自适应通过只读系统偏好及辅助功能布局获取尺寸。系统 Dock 暂不可读时保留最近有效尺寸，无历史值时使用兼容值。已读取的辅助功能边界不保证与系统绘制像素完全一致。

macOS 14+，本次安装包为 Apple Silicon。个人构建采用 ad-hoc 签名，未经 Apple 公证。下载 DMG 后拖到 Applications；校验文件与安装包一起提供。

## English

- Fully adaptive sizing follows the system Dock's base icon size, bar thickness, spacing, end padding, and magnification. The centered bar grows or shrinks with its contents. Manual controls are hidden while adaptive mode is enabled, and previous manual values are retained.
- Choose bottom, top, left, or right independently for each display. Side Docks use upright icons in a vertical row; groups and previews open inward.
- Resize manually from the inward edge, either endpoint, or the two inward corners. A separate icon-size control sets the proportion preserved during later resizing.
- Synchronize sizes across displays or configure each display independently. Re-enabling synchronization adopts the currently selected display's effective size; positions stay independent.
- Redesigned settings use a sidebar, dedicated configuration pages, and an About page in a resizable window.
- Existing groups, order, badges, preview close buttons, and permissions are preserved. The previous configuration is backed up on migration.

Native dimensions are read from system preferences and Accessibility geometry. Temporary read failures retain the latest valid measurement; compatible values are used if none is available. Accessibility bounds are not a guarantee of pixel-identical system rendering.

Requires macOS 14+. This DMG targets Apple Silicon and uses an ad-hoc signature; it is not Apple-notarized. Drag the app to Applications. A SHA-256 checksum accompanies the DMG.
