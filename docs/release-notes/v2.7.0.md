# DualDock 2.7.0

- 设置采用 macOS 原生分类工具栏。选择 Dock、交互、通用或支持，在左侧进入子项，按 ⌘F 可搜索中英文设置。
- 改进 Muse 等带浮动辅助窗口的应用唤出。点击预览后，DualDock 核对实际显示的窗口。
- 预览仅为可准确识别且提供原生关闭操作的窗口显示 ×。关闭失败时在卡片内提示，鼠标移开即可收起。

## English

- Navigate settings using the native macOS toolbar and source list. Press ⌘F to search settings in Chinese or English.
- Improved reopening apps with floating utility panels, including Muse. DualDock verifies which window came forward after selecting a preview.
- Preview cards show a close button when the target exposes an actionable native Close control. A stale target displays feedback within its preview.

macOS 14+ on Apple Silicon. The DMG includes first-launch instructions. [Installation guide](https://github.com/autumncry/DualDock/blob/v2.7.0/README.en.md)
