# DualDock 2.4.0

## 中文

- 设置页改用五个固定示例图标，随大小、间距、长度和位置变化，不再展示实际打开的应用列表。
- “高级设置”的箭头、标题和标题行空白处均可点击展开或收起。
- 用统一的0–100“图标间距”取代“疏密”：0让可见边界贴合，100留出约一个图标宽度。抵消图片透明留白，同时保持原始图标大小与形状；四向排列、分组、点击区域、角标与运行圆点一起适配。
- 新增“登录时启动”开关，位于“通用”。默认不主动注册，系统需要批准时提供对应入口。
- 中英文 README 和 DMG 安装指南加入用户实测有效的可选 xattr 命令，原“仍要打开”步骤继续保留。
- 升级保留现有分组、权限、尺寸和屏幕位置；旧间距在首次调整新滑块后才采用新规则。配置升至schema11，迁移前保留原文件备份。

macOS14+，Apple Silicon。提供DMG与SHA-256，ad-hoc签名，未经Apple公证。首次启动步骤见[安装指南](https://github.com/autumncry/DualDock#首次启动apple-无法验证或无法验证开发者)，同样包含在DMG的“安装说明.txt”中。

## English

- Settings now uses five fixed sample icons that respond to sizing and positioning without mirroring the real running-app list.
- The entire Advanced Settings header toggles its content.
- A unified0–100 Icon Spacing slider replaces Density. Zero joins visible artwork bounds;100 leaves about one icon width. Artwork keeps its original scale and shape, with four-edge layout, groups, hit regions, badges and running indicators aligned to content.
- Added opt-in Launch at Login in General, backed by macOS status and an approval link when needed.
- Both READMEs and DMG installation notes include the user-tested optional xattr route while retaining the GUI Open Anyway guide.
- Existing layouts remain until spacing is edited. Schema11 keeps a pre-migration backup and preserves groups, permissions and display positions.

Requires macOS14+ on Apple Silicon. DMG and SHA-256 assets; ad-hoc signed, not Apple-notarized. See the [installation guide](https://github.com/autumncry/DualDock/blob/main/README.en.md#first-launch-apple-cannot-verify-the-app-or-developer).
