# DualDock 2.1.2

## 中文

- 修复鼠标越过首尾图标时整行图标继续跟随指针移动的问题。末端定位不再持续追随指针，移出后正常收回；快速跨过整排时保留目标图标的点击位置。
- 同时覆盖底部、顶部、左右侧的布局；保留邻近图标联动、手动溢出滚动和固定底板。
- 保留现有分组、曲线参数、尺寸、位置、最大化隐藏选项及权限。

macOS 14+，Apple Silicon。采用 ad-hoc 签名，未经 Apple 公证。提供 DMG 与 SHA-256 校验文件。

## English

- Fixed the entire icon row following the pointer beyond either terminal icon. Endpoint magnification no longer pulls the row after the pointer and returns normally on exit. Quick moves across the row preserve the target icon's clickable position.
- Covers all four Dock orientations while retaining neighboring magnification, manual overflow scrolling, and a fixed backdrop.
- Preserves existing groups, curve settings, dimensions, positions, maximize hiding, and permissions.

Requires macOS 14+ on Apple Silicon. The build is ad-hoc signed and not Apple-notarized. DMG and SHA-256 assets are provided.
