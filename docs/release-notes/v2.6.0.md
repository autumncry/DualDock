# DualDock 2.6.0

在**设置 → 交互 → 消息提醒**中拖动“角标大小”，即可在 75%–200% 之间同时调整应用的数字角标和分组的红色叹号。默认值为 100%。各屏幕上的 Dock 和已展开的分组会同步更新。极小的图标使用随比例变化的红点。

In **Settings → Interaction → Notifications**, the new **Badge size** slider scales app counts and group exclamation marks together from 75% to 200%. The default is 100%. Changes apply across displays and inside open groups. Very small icons show a scaled notification dot.

适用于 macOS 14 或更新版本的 Apple Silicon Mac。DMG 内含首次启动说明。 [Installation guide](https://github.com/autumncry/DualDock/blob/v2.6.0/README.en.md)
