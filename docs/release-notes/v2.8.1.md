# DualDock 2.8.1

- 设置窗口会根据所选页面和实际内容调整高度。手动拖动上下边缘调整高度后，本次打开期间使用你选定的高度。
- “窗口与预览”将开关、用途和点击行为集中在一组。通用、权限、消息提醒等页面将说明与对应控件对齐，减少重复标题和间隔。
- 外观页的 Dock 示例缩短，多显示器设置改为列表，使用方法与关于页收紧排布。

The settings window fits the selected page. Short pages open in a smaller window, and longer pages scroll as needed. Resizing vertically keeps your chosen height until settings closes. The layout update covers all four toolbar categories, including window previews, display positioning, and About.

2.8.0 用户可在 **支持 → 关于 DualDock → 检查更新** 安装本版。The DMG includes the first-launch guide for Apple Silicon Macs running macOS 14 or later.
