# DualDock 2.8.7

- 右键点按尚未固定的活动应用，选择 **加入应用组 → 组名**，即可将它固定到该组末尾。子菜单按 Dock 中的顺序列出已有分组。
- 应用组图标改用浅银灰圆角托盘。前四个成员的真实图标按 2×2 排列，展开后可查看全部成员。有未读消息时，组图标继续显示红色叹号。

## English

- Right-click an unpinned running app and choose **Add to App Group**, then pick an existing group. The app is pinned at the end of that group.
- Group icons now show the first four members on a softly rounded silver tray. Click a group to see all its apps. The red exclamation badge still indicates unread items.
