# DualDock 2.2.2

## 中文

- 修复应用组或窗口预览弹出后，未被覆盖的 Dock 边缘也无法再次拖动调整尺寸的问题。弹窗只占用实际覆盖的区域，开始拖动时收起弹窗；菜单打开期间仍暂停缩放。
- 设置与帮助中的“厚度”统一改为“高度”，图标大小同时显示实际尺寸和占栏高的百分比。
- 补充高度与图标大小、内侧边与角落拖动的区别，以及自动长度模式下留白如何变化。

macOS 14+，Apple Silicon。采用 ad-hoc 签名，未经 Apple 公证。升级保留分组、排列和尺寸设置。

## English

- Fixed exposed Dock edges becoming unavailable for another resize while an app group or window preview was open. Popups retain input ownership only over the area they cover, and beginning a resize dismisses them. Resizing remains suspended while a menu is open.
- Renamed thickness to height in settings and help. Icon size now shows both its actual size and its percentage of the bar height.
- Clarified bar height versus icon size, inward-edge versus corner resizing, and how end padding behaves with content-driven length.

Requires macOS 14+ on Apple Silicon. The build is ad-hoc signed and not Apple-notarized. Existing groups, ordering, and sizing preferences are preserved.
