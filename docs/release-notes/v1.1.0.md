# DualDock v1.1.0

本版集中改进多屏尺寸、悬停动画、窗口预览与文件夹样式。

## 改进

- 修复小屏图标尺寸提前达到上限、只有外接屏响应大小设置的问题。全部屏幕共用同一逻辑尺寸，屏幕宽度只约束可见区域，超长内容横向滚动。
- 两个连续滑块分别控制 Dock 整体大小和图标间距。设置与模式按钮固定在栏右侧。
- 增加鼠标附近图标的平滑波形放大，支持开关和放大幅度。动画状态每屏独立；拖拽、菜单期间冻结图标，遵循“减少动态效果”。
- 只显示本次成功取得、具有可见内容的窗口截图。无图、全透明、重复 ID 和已经关闭的窗口不生成预览卡片；不同 ID 的同标题真实窗口继续保留。
- 单窗口预览在窗格内居中，多窗口保持等距布局，超宽时可以滚动。
- 切换悬停目标时及时关闭旧窗格，避免旧窗格的退出计时取消新预览；悬停判定采用完整可交互区域，弹窗定位采用当前图标的视觉边界。
- 右键和 Control-click 菜单位于当前图标上方，并约束在当前屏幕内；支持辅助功能打开菜单。
- 应用组改用带顶签的文件夹轮廓、前后层面和内部小图标，与普通 App 图标区分。

## 配置与验证

旧配置自动迁移到 schema 2，保留分组、排列和已有开关，迁移前保存 `configuration-before-v2.json`。新参数使用兼容默认值。

46 项自动测试通过，覆盖旧配置迁移、连续参数、双屏尺寸一致、放大波形与动画收敛、图像有效性、窗口身份和预览居中。使用实际 DockStripView 的隔离反馈环确认，在 1768 与 2976 pt 两种可见宽度下，32、48、63.375、72、96 pt 都能得到一致的实际图标尺寸。

实际窗口截图反馈环确认 Clash Verge、CC Switch 各一张有效图；模拟 AX 查询覆盖未知时也不会再产生透明卡片。截图只在内存中处理。

所有交互动画与不同屏幕组合的完整人工验收仍需继续，已完成与未完成项见 `docs/validation.md`。

## 安装

下载 `DualDock-1.1.0-arm64.dmg`，将应用拖到 Applications。此版本为 Apple Silicon 构建，最低部署目标 macOS 14，本次环境为 macOS 27.0.1 / Apple M5。
