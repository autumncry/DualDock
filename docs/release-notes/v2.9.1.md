# DualDock 2.9.1

- 修复微信独立浏览器图标可以唤起网页、再次点却无法收起的问题。DualDock 会核对图标所代表的网页窗口，并对同一扇窗口执行前置、最小化或还原。多个微信窗口难以区分时，可右键该图标选定目标窗口。
- 活动区现在会监听 macOS 运行应用列表和应用身份的变化。先在后台启动、随后才注册为普通 Dock 应用的进程，可以及时显示图标；转回后台身份时，图标也会及时移除。

## English

- Fixed repeated clicks on WeChat’s separate browser icon. DualDock identifies the corresponding window and can bring it forward, minimize it, or restore it. If more than one WeChat window could be the target, choose one from the icon’s context menu.
- Running app icons now update when macOS changes an app’s Dock eligibility, including apps that start in the background and register their Dock icon later.
