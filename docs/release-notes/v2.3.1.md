# DualDock 2.3.1

## 中文

- 按确认的草案细化原生设置页：统一左侧导航、字体层级和控件对齐，Dock 预览置于常用设置上方，兼容明暗主题与小窗口。
- 修复实时预览：使用固定的 50% / 75% / 100% 比例，调整图标大小不再被自动适配抵消。超出预览区域可滚动查看，显示实际尺寸及空间限制。
- “关于”沿用新的简洁布局，同时保留版本与构建号、作者与版权、MIT、项目主页、下载、反馈和支持入口。
- GitHub 中英文安装说明及 DMG 内的“安装说明.txt”补齐首次启动被 Apple 阻止时的具体处理步骤。
- 将首次启动说明列为持续发布要求：打包前检查文档，再只读挂载 DMG 验证说明文件一致。正式完成 Developer ID 签名与 Apple 公证前保留。
- 保留现有应用、分组、权限、尺寸及各屏幕位置；配置版本仍为 schema 10。

macOS 14+，Apple Silicon。提供 DMG 与 SHA-256 校验文件。当前采用 ad-hoc 签名，尚未经过 Apple 公证。

首次启动若提示“Apple 无法验证”或“无法验证开发者”，从本项目官方 Releases 下载并确认来源可信后，先尝试打开一次，再到 **系统设置 → 隐私与安全性 → 仍要打开**，按提示验证并选择“打开”。找不到入口时再次尝试启动后返回该页。完整说明见 [安装指南](https://github.com/autumncry/DualDock#首次启动apple-无法验证或无法验证开发者)。

## English

- Refined native settings with consistent sidebar typography, aligned controls, and one Dock preview above the primary settings. Supports Light/Dark and compact windows.
- Fixed live preview scaling: explicit 50%, 75%, or 100% zoom preserves visible size changes. Scroll overflow and inspect the actual size and any space constraint.
- Preserved complete version, build, author, copyright, MIT, project, download, feedback, and support information in the redesigned About page.
- Added concrete first-launch Apple verification instructions to both READMEs and the DMG installation notes.
- Added a persistent release check for source documentation and the identical text in the read-only mounted DMG. Keep this guidance until Developer ID signing and Apple notarization are established.
- Existing apps, groups, permissions, sizing, per-display positions and schema 10 remain intact.

Requires macOS 14+ on Apple Silicon. DMG and SHA-256 assets; ad-hoc signed, not Apple-notarized. If first launch reports an unverified developer, follow the per-app approval steps in the [installation guide](https://github.com/autumncry/DualDock/blob/main/README.en.md#first-launch-apple-cannot-verify-the-app-or-developer).
