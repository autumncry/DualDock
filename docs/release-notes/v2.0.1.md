# DualDock 2.0.1

## 中文

- 优化设置侧栏：统一图标视觉尺寸、文字起点和行距，“屏幕与位置”使用更均衡的单屏符号。
- 重画状态栏图标：沿用彩色 App 图标的错叠双屏与应用方块，采用单色矢量模板，适配系统明暗外观。
- 更新标语为“应用有序收纳，Dock 多屏同在。”，同步更新“关于”和中英文 README。

本次为界面细化，保留现有应用分组、尺寸、位置和权限配置。

macOS 14+，安装包适用于 Apple Silicon。采用 ad-hoc 签名，未经 Apple 公证。DMG 与 SHA-256 校验文件一并提供。

## English

- Refined the settings sidebar with consistent icon bounds, text alignment, and row spacing. Displays & Position now uses a balanced single-display symbol.
- Redesigned the menu bar icon around the colored app icon's overlapping displays and Dock tiles. The monochrome vector template follows the system appearance.
- Updated the tagline: “Apps neatly organized. A Dock on every display.” The About page and both READMEs now use the new wording.

This UI update preserves existing app groups, dimensions, display positions, and permissions.

Requires macOS 14+. The Apple Silicon DMG uses an ad-hoc signature and is not Apple-notarized. A SHA-256 checksum is included in the release.
