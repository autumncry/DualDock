# DualDock 2.3.0

## 中文

- 重新设计原生设置页：实时 Dock 预览、屏幕位置示意、精简侧栏、明暗外观与分类滚动复位。
- 尺寸设置改为大小、疏密、长度三个常用入口；高级参数可单独固定或恢复自动，并支持精确数值输入、对齐及溢出处理。升级保留已有布局，schema10迁移前保留备份。
- 右键应用图标列出可选择的窗口，包括已最小化窗口，并标记当前目标。
- 反复点击图标可前置、最小化及还原选中的普通窗口。全屏和最大化窗口只激活；使用原应用的原生窗口动作。
- 全屏下支持边缘唤出 DualDock，分组和预览随屏幕进入全屏空间；其他屏幕保持独立。
- 修复过期窗口读取、取消任务及原生恢复回调的时序问题，避免错误选择或重新还原已收起的窗口。
- 原生动画期间即使系统应答延迟，也会确认窗口实际状态，不再误报“不支持最小化”。

macOS14+，Apple Silicon。提供DMG与SHA-256校验文件，ad-hoc签名，未经Apple公证。

## English

- Redesigned native settings with a live Dock preview, clickable display positioning, a compact sidebar, adaptive appearance, and scroll reset on category changes.
- Added Size, Density, and Length as primary controls, with precise advanced overrides, individual automatic resets, alignment, and overflow behavior. Existing layouts are retained with a pre-migration configuration backup.
- Added window selection at the top of app context menus, including minimized windows and a selected-target checkmark.
- Repeated icon clicks activate, minimize, and restore the selected ordinary window. Fullscreen and maximized windows remain activation-only, using native app window actions.
- Added fullscreen edge reveal with per-display overlay membership for the Dock, groups, and previews.
- Hardened stale window reads, canceled work, and delayed native recovery callbacks.
- Confirm native window state after delayed animation replies instead of incorrectly reporting minimization as unsupported.

Requires macOS14+ on Apple Silicon. DMG and SHA-256 assets, ad-hoc signed and not Apple-notarized.
