# DualDock v1.0.0

首个个人使用版本，支持 macOS 14 及以上。本次 DMG 为 Apple Silicon（arm64）构建。

## 功能

- 多个应用拖拽成组，点击后横向展开，支持重命名、组内排序及移出。
- 悬停查看已打开窗口的缩略图，点击切换到对应窗口。
- 普通模式显示固定应用、分组及未固定的运行应用；仅运行模式平铺全部普通运行应用，保留原分组配置。
- 各逻辑显示器分别显示 Dock，共享布局；镜像屏随系统复制，某屏全屏时隐藏该屏的栏。
- 首次导入系统 Dock 固定应用，后续独立管理。提供重新导入入口及可选的系统 Dock 隐藏开关。

## 安装

下载 `DualDock-1.0.0-arm64.dmg`，打开后将 `DualDock.app` 拖到 `Applications`。
在应用的“权限”页授予屏幕录制和辅助功能，按需开启系统 Dock 隐藏。

校验下载文件：

```sh
shasum -a 256 -c DualDock-1.0.0-arm64.dmg.sha256
```

本版本采用 ad-hoc 临时签名，未经过 Developer ID 签名和 Apple 公证。macOS 可能拦截首次打开，确认下载来源后可在“系统设置 → 隐私与安全性”中允许打开。

## 验证范围

12 项模型测试与 10 项系统 Dock 恢复检查通过。DMG 校验、只读挂载、复制安装后的签名和文件完整性检查通过。已验证在 MacBook 内屏和外接 P32A6V 显示器上创建内容一致的两张 Dock 面板。

当前仍待解锁并授予新应用权限后完成拖拽交互、实际预览截图、指定窗口切换、全屏转换和显示器插拔的完整验收。系统 Dock 恢复检查使用内存偏好注入，尚未实际切换用户的系统 Dock 设置。窗口匹配及全屏判断使用可选私有接口，系统更新后可能需要适配。
