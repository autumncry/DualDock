# DualDock 2.1.1

## 中文

- 自动隐藏改为“最大化窗口时隐藏 Dock”：窗口铺满该屏工作区才触发。普通窗口轻微擦边，或向下移动后盖住整个 Dock，均不因重叠隐藏。原开关状态保留。
- 真正全屏仍独立隐藏；普通最大化时保留边缘唤出，应用夹、菜单、预览与拖拽继续保持显示。
- 为 Cursor 等应用的跨桌面窗口增加保护性唤起回退：保留系统原生打开流程；若准确的应用实例仍在前台且没有可见内容窗口，再后台恢复它明确的 focused/main 窗口。不会移动、缩放窗口或退出全屏。
- 窗口快照读取失败时，旧记录最多保留约1秒，避免过期状态长期影响 Dock。

配置、分组、排列、尺寸与权限保留。macOS 14+，Apple Silicon；采用 ad-hoc 签名，未经 Apple 公证。提供 DMG 与 SHA-256 校验文件。

## English

- Auto-hide now responds to maximized windows that fill a display's available workspace. Ordinary overlap, including a window moved down over the entire Dock, no longer triggers hiding. The saved toggle state is retained.
- Native fullscreen still hides independently. Edge reveal and interaction protection remain available for normal maximized windows.
- Added guarded recovery for existing windows on another Space, including Cursor: native reopen runs first; only the exact, still-active app with no visible content window receives a bounded background focused/main-window recovery. Windows are never moved, resized, or taken out of fullscreen.
- Failed window snapshots can retain old geometry for at most about one second.

Existing configuration, groups, order, dimensions, and permissions are retained. Requires macOS 14+ on Apple Silicon. The build is ad-hoc signed and not Apple-notarized. DMG and SHA-256 assets are included.
