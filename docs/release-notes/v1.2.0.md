# DualDock v1.2.0

## 放大与菜单修正

- 固定 Dock 的水平位置、宽度和滚动范围。悬停只改变图标和邻居的几何及栏高度，去掉鼠标跟随窗口和横向滚动补偿。
- 不显示滚动条；只有应用内容真正溢出时，用户的横向滚轮／触控板操作才需要滚动。放大预留空间不再制造空白滚动范围。
- 右键菜单从图标中心略偏右的位置向上展开，屏幕边界仍优先约束。

## 消息数量角标

- 新增“显示消息数量角标”开关，默认开启。
- 单个应用同步系统提供的数量或标签；应用组有未读提醒时显示红色叹号，展开后仍显示每个 App 自己的数量。
- 优先读取 LaunchServices 状态标签，必要时使用原生 Dock 的辅助功能数据补充。已实测微信与飞书。
- 后台两秒轮询，只重绘角标，不重新排列 Dock。关闭后立即清除，并丢弃在途结果。
- 无可读取标签时不显示角标，不用0代替未知数据。不同应用是否提供状态标签仍由应用和系统决定。

## 验证与安装

59项主测试、7项角标服务检查及10项系统 Dock 恢复检查通过。固定水平几何已通过 Core 与实际 AppKit 离屏回放，包含多个焦点、插值帧、手动 offset、小数尺寸和真实溢出场景。原版本回放失败，新版本通过。正式安装界面已确认出现数量角标和组叹号。滚轮输入的完整人工验收仍待继续；没有把离屏设置 offset 当作真实手势已通过。

配置自动升级为 schema 3，保留分组与外观，升级前备份。下载 `DualDock-1.2.0-arm64.dmg` 后将应用拖到 Applications。

Apple Silicon 版本，最低部署目标 macOS 14，本次环境 macOS 27.0.1 / Apple M5。采用 ad-hoc 签名，尚未 Apple 公证。MIT License，仓库保持私有。
