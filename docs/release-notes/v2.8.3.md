# DualDock 2.8.3

- 修复从主栏或应用夹点击 Muse 时，主窗口可能仍被 ChatGPT 等应用挡住的问题。DualDock 现在会检查所选窗口在桌面上的实际前后顺序，已被其他普通窗口盖住的窗口会优先前置。
- 从预览选择窗口时使用相同的检查。若辅助功能清单暂时不可用，后续点击图标会尝试找回先前选择的同一扇窗口。

## English

- Fixed an issue where clicking Muse in the Dock or an app group could leave its window behind another app. DualDock now checks the order of overlapping windows before choosing to minimize and after requesting activation.
- Preview selections use the same foreground check. If the accessibility window list is temporarily unavailable, clicking the app icon can recover the previously selected window by its original identity.
