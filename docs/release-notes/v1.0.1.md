# DualDock v1.0.1

修复实机验收中发现的空白预览卡片。

## 修复

- 过滤屏外、无标题且无法由辅助功能确认的后台窗口，避免把 TextEdit 的全透明辅助表面作为窗口预览。
- 保留有标题的其他桌面窗口、屏上无标题窗口，以及辅助功能能确认的最小化窗口。辅助功能或窗口 ID 查询不可用时采用保守保留，避免把查询失败误判为窗口不存在。
- 真实窗口暂时无法截图时显示较小的应用图标和“预览暂不可用”提示，保留点击切换入口。

## 验证

- 新增 7 项窗口筛选回归。旧策略复现失败，修正后模型及筛选测试共 19 项通过。
- 使用实际 WindowService 对临时 TextEdit 文档复测，只返回 A、B 两个窗口，两张缩略图均为 480×308、有可见内容。
- 正式安装版已确认屏幕录制与辅助功能授权生效。
- 双屏模式切换、分组数据保留和内屏全屏时只隐藏内屏 Dock 已完成实机检查；用户确认拖拽成组及横向展开成功。

跨 Space 全屏窗口的截图仍受 macOS 限制；本次未宣称消除全部跨桌面截图限制。指定预览卡片点击、外屏全屏、显示器热插拔/镜像及真实系统 Dock 恢复仍有待完成实机验收。

## 安装

下载 `DualDock-1.0.1-arm64.dmg`，将应用拖到 Applications。升级保留 `~/Library/Application Support/DualDock/` 中的个人布局和分组。

最低部署目标 macOS 14，本次验证环境 macOS 27.0.1 / Apple M5。此包为 Apple Silicon arm64，采用 ad-hoc 临时签名，尚未 Apple 公证。
