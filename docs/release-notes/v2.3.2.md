# DualDock 2.3.2

## 中文

- 修复运行状态圆点的位置：增加 Dock 高度时，圆点跟随图标，保持贴近，不再停留在底板边缘。底部、顶部、左侧、右侧以及悬停放大均保持对齐。
- 去掉失效窗口目标留下的设置页提示：窗口已关闭、发生变化或暂时无法识别时，不再持续显示“请重新选择”，也不会因此误操作其他窗口。
- 保留已有分组、尺寸、权限和各屏位置；配置保存等需要处理的提示不受影响。

macOS 14+，Apple Silicon。提供 DMG 与 SHA-256 校验文件。当前采用 ad-hoc 签名，尚未经过 Apple 公证。首次启动被系统阻止时，请按 [安装说明](https://github.com/autumncry/DualDock#首次启动apple-无法验证或无法验证开发者) 操作；同样的完整步骤保留在 DMG 的“安装说明.txt”中。

## English

- Running indicators now stay near their icons when Dock height increases, instead of remaining at the backdrop edge. All four positions and hover magnification keep the indicators aligned.
- Unavailable or expired window targets no longer leave persistent warnings in Settings or cause a different window to reopen.
- Existing groups, sizing, permissions and per-display positions remain intact. Actionable configuration warnings remain available.

Requires macOS 14+ on Apple Silicon. DMG and SHA-256 assets; ad-hoc signed and not Apple-notarized. See the [first-launch instructions](https://github.com/autumncry/DualDock/blob/main/README.en.md#first-launch-apple-cannot-verify-the-app-or-developer), also retained inside the DMG.
