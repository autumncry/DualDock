# DualDock 2.8.0

- 首次安装时，DMG 中的“首次安装 - First Launch.html”提供中英文离线指南和复制命令按钮。默认路径为 macOS“隐私与安全性”中的“仍要打开”，可选终端命令由用户确认并执行。
- 打开 **支持 → 关于 DualDock → 检查更新…** 可手动检查新版本，阅读发布说明并确认下载安装。Sparkle 验证签名后替换应用并重新启动。
- 2.7.0 或更早版本需要从本发行页手动安装一次 2.8.0。应用仍以 ad-hoc 方式签名，首次启动说明随 DMG 分发。

Open **Support → About DualDock → Check for Updates…** to check on demand. Sparkle authenticates updates and offers to install and relaunch. This is the first release with the updater. Install it manually once when upgrading from 2.7.0 or earlier. The DMG also includes a bilingual offline installation guide with a copy-to-clipboard button.

Requires macOS 14 or later on Apple Silicon. [Installation guide](https://github.com/autumncry/DualDock/blob/v2.8.0/README.en.md)
