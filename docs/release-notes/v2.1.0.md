# DualDock 2.1.0

## 中文

- 新增可选的“窗口遮挡时隐藏 Dock”：普通窗口重叠时按屏幕隐藏，鼠标到对应边缘停留后唤出。应用夹、预览、菜单和拖拽使用中保持可见，真正全屏仍优先隐藏。旧配置升级默认关闭。
- 手动模式新增两个独立曲线滑块：“放大峰值”控制中心图标的最大尺寸，“联动范围”控制相邻图标的放大范围，并提供曲线预览。完全自适应模式仍跟随系统 Dock。
- 修复拖动尺寸跨过内容溢出临界点时的画布突变，合并视图和面板更新，减少底板抖动。
- 全屏可见性改为响应 Space 变化并通过 100ms 轻量检查补充；慢速辅助功能查询转到后台。未知结果不会无限保留旧全屏状态。
- 修正微信网页等嵌套辅助应用的激活路径，切换到已有辅助进程，避免重新打开辅助应用包；普通应用保留 macOS 原生重新打开行为。
- 减少悬停动画中不必要的布局和图标重绘，及时结束不可见的缩小尾差。在 360 帧隐藏 AppKit 回放中，绘制次数从 10,080 降至 5,994；这不等同于实际屏幕帧率。

保留现有应用组、排列、各屏尺寸和位置。原有手动放大峰值保留，新增联动范围默认延续旧版效果；关闭自适应后恢复保存的手动曲线设置。

macOS 14+，安装包适用于 Apple Silicon。采用 ad-hoc 签名，未经 Apple 公证。DMG 与 SHA-256 校验文件一并提供。

## English

- Added optional “Hide when windows overlap.” Each display's Dock hides when a normal window overlaps it and returns after a brief pointer dwell at that edge. Groups, previews, menus, and drag operations keep it visible; native fullscreen takes priority. The option is off by default on upgrade.
- Added two independent manual magnification controls: peak size and influence range, with a curve preview. Fully adaptive mode continues to follow the system Dock.
- Fixed the canvas discontinuity when resizing across the content-overflow boundary and combined view and panel updates to reduce backdrop movement.
- Fullscreen visibility now responds to Space changes with a lightweight 100ms check as a fallback. Slow Accessibility queries run in the background, and unknown results cannot retain an old fullscreen state indefinitely.
- Corrected activation of embedded helpers such as WeChat web windows by targeting the existing helper instance instead of reopening its bundle. Ordinary apps retain macOS's native reopen behavior.
- Reduced unnecessary layout and icon drawing during hover animation and settled imperceptible shrinking tails. A 360-frame hidden AppKit replay reduced draw calls from 10,080 to 5,994; this is not a measurement of on-screen frame rate.

Existing groups, order, per-display dimensions, and positions are retained. The saved manual peak is preserved, and the new influence range initially matches the previous behavior. Disabling adaptive mode restores the saved manual curve settings.

Requires macOS 14+. The Apple Silicon DMG uses an ad-hoc signature and is not Apple-notarized. A SHA-256 checksum accompanies the release.
