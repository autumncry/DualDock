# DualDock 2.2.0

## 中文

- 新增“随应用数量自动增减长度”：保留手动厚度、图标比例、间距和两侧留白，随着应用或分组增减居中伸缩。达到屏幕上限后可手动滚动，不显示滚动条。
- 保留长度滑块和两端拖动，用于重新设定留白。关闭选项恢复此前的固定长度；完全自适应系统 Dock 模式保持原有行为。
- 优化尺寸滑块和边缘拖动的更新路径：复用现有图标、合并布局更新、保留滚动位置，连续调节不再逐样本同步写入配置。
- 保留现有分组、位置、曲线和权限。新选项默认关闭，位于“外观与尺寸”的手动模式下。

macOS 14+，Apple Silicon。采用 ad-hoc 签名，未经 Apple 公证。提供 DMG 与 SHA-256 校验文件。

## English

- Added content-driven length in manual mode: preserve thickness, icon proportions, spacing, and end padding while the centered bar grows or shrinks with visible apps and groups. At the display limit, extra content scrolls manually without a scrollbar.
- The length slider and endpoint dragging redefine end padding. Disabling the option restores the earlier fixed length; fully adaptive system Dock sizing is unchanged.
- Improved slider and edge-resize updates by reusing icon views, coalescing layout changes, preserving scroll position, and avoiding a synchronous configuration write for every continuous sample.
- Preserves groups, positions, curve settings, and permissions. The new option defaults to off and is available in the manual Appearance & Size settings.

Requires macOS 14+ on Apple Silicon. The build is ad-hoc signed and not Apple-notarized. DMG and SHA-256 assets are provided.
